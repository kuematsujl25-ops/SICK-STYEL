# 完了タスクの自動整理

通常タスクと担当者別タスクは、完了後7日（168時間）を経過するとゴミ箱へ移動します。毎時7分に既存の分次Cron内で確認します。物理削除、追加Cron、DBスキーマ変更は行いません。ゴミ箱に期限はなく、画面から復元できます。

完了日時はサーバーが記録します。未完了へ戻すとカウントを解除し、再完了で開始し直します。完了状態でゴミ箱から復元した場合は復元から7日間表示します。編集だけでは期間を延長しません。導入前から完了していたタスクは、正確な完了日時が不明なため初回確認から7日間の猶予を設けます。

ゴミ箱も既存の保存上限に含まれます。自動整理は保存容量の削減機能ではありません。定期生成の履歴は残るため二重生成されません。旧クライアントやバックアップでゴミ箱のレコードが欠落しても保持します。更新はrevisionの比較更新で競合を再試行します。

発送管理、AI社員の提案、情報収集は対象外です。人が使う通常・担当者別タスクが対象です。
