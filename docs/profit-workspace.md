# 利益・在庫ワークスペース（Phase 3）

既存の黒・白・シルバーとロゴを継承し、「利益・在庫」を追加しました。PCは3列の利益カード、スマートフォンは1列。商品テーブルは横スクロールで確認できます。Canvaのコネクタはこの環境にはなく、Canva素材・既存デザインは変更していません。Canva Freeでのデザイン移管時は既存ロゴとこの配色・余白を使い、素材の権利を人間が確認してください。

ログイン後、AI COOのJSONレポートを読み込み、売上・粗利・貢献利益・SKU在庫・販促可否を確認します。商品フィルターと表示消去を実装しています。入力は5MiB以下、SICK STYLE限定。未知費用は「未取得」、未知費用・在庫不足・赤字の販促候補は拒否します。粗利と貢献利益の計算一致・SKU合計・重複を検証します。

入力元の真正性や計算に使った元データは、JSONの検証だけで保証できません。取得元と日時を表示し、人間が確認します。テストは架空のSKUを使っています。読み込んだレポートはメモリーのみで扱い、サーバーやlocalStorageへ送信・保存しません。再読み込み・ログアウト時に破棄します。既存の認証・業務データAPI・PWAを継続使用しています。

追加費用・新規依存・本番DB変更はありません。CloudflareとNodeで同じ`public/finance.js`を配信します。`npm test`は既存15件と利益レポート検証10件を実行します。PC 1440px・iPhone相当390pxのChromiumで、ログイン・遷移・取込・フィルター・消去・不正ファイル拒否・横幅を検証しました。iOS Safariの実機検証は未実施です。

InstagramのOAuth・Insights・トークン更新、AmazonのLWA・Sales/Ordersは既存実装を利用します。実認可・最新の無料枠・本番同期はこの作業では未確認です。`integrations/README.md`の「Amazon未実装」という記述は実コードと不一致です。SP-APIとAdsは別であり、SKU原価・手数料・在庫まで自動取得できるとは判断していません。

BASE・TikTok・Metricool・CapCut・Google Sheetsの実接続、リピート率、流入売上寄与、SNS/EC下書きの自動生成は今回未実装です。無承認のAI API・投稿・営業送信・広告・価格変更・発注は追加していません。

公開は人間がレビューして判断します。コードのロールバックはこのPhase 3コミットのrevertです。DB移行を伴いません。サービスワーカーは新バージョンを使います。
