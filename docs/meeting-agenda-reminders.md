# 今日の会議と開始前通知

ダッシュボードに保存済み団体/OEM会議を日本時間・開始順で表示する。前日から続く会議を含み、当日終了済みの会議も残す。会議一覧・編集画面からもZoom参加URLを開ける。リンクはHTTPSのzoom.us配下の参加用パスのみ許可し、新しいタブで開く。URL未作成、取消確認中、処理中、結果不明を区別する。完全取消は既存処理が開始日時を消すため一覧から外れる。

## 通知

- アプリ内：ログイン中、全画面の上部に開始10分前〜開始直前の予定を表示。既存の60秒更新・focus・visibilitychangeで最新データを取得する。更新失敗時は古い通知を消し、ダッシュボードに取得失敗を表示。ブラウザ通知権限がなくても表示する。
- OS：既存Cloudflare Cronへ毎分確認を追加。D1の通知履歴と既存Web Push購読を利用する。アプリを閉じていても配信可能だが、端末の通知許可・購読・有効なアプリログイン・通信が必要。iPhoneはSafariからホーム画面追加したアプリで通知登録する。
- 予定ID＋会議枠＋開始日時のハッシュをDB一意キーにして重複を防ぐ。複数タブ・再読込・Cron再試行は同じ通知を再送しない。日程変更は新しいキー。DB挿入時にワークスペースrevisionを照合し、同時変更時の古い予定を記録しない。
- 取消確認中・処理中・結果不明・削除済みは対象外。送信直前と端末受信時に現在の予定を再確認。TTLは開始まで（最大600秒）で、開始後・取消済み・検証不能では「まもなく開始」の案内を表示せず、一般的な予定確認のお知らせにする。Safariのuser-visible push要件を守り購読失効を防ぐため、受信済みプッシュを無表示では捨てない。送信済み通知は変更・取消で端末から回収できない。履歴は作成当時の予定と明記する。
- 毎分実行のため厳密な10分前保証ではない。遅延実行は開始前の10分間に限り追いつく。開始後は送らない。1実行最大2予定・各最大5登録端末に制限し、超過は次回へ回す。通信・OS制限・Cron遅延・配信失敗で未着となる可能性がある。記録後のPush失敗は自動再送しない（既存配信仕様）。
- 会議タイトルやURLはOS通知に含めず、アプリ内にのみ表示する。クリックはアプリの会議一覧へ進み、Zoomへ自動参加しない。
