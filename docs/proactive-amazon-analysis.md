## 数値の定義

- 当日を除く日本時間直近7日と前7日。Sales APIの最新31日応答から、7日すべて存在し重複がなく項目が取得できた場合にのみ売上・注文数・個数を集計。手入力や別APIの値は混ぜない。
- Orders APIの既存レスポンスから商品名・SKU・ASIN・数量・日付・配送状態・明細識別子をallowlistで保存。リクエストのincludedData、OAuth、ロール、Secretsは拡張しない。購入者、住所、カスタマイズ、シリアル番号は保存しない。
- 商品金額は応答に存在する場合のproceeds.breakdownsのITEM小計（JPY）だけ。既存リクエストでは未取得の可能性があり、単価×数量や全体売上の按分で補完しない。金額未取得でも数量は取得可能。
- 商品別はSKUとASINの組合せ。確定した配送状態の注文だけ数量集計し、CANCELLED/PENDING/PENDING_AVAILABILITY/UNFULFILLABLEは除外。キャンセル・保留は明細数として別表示。返品・返金は未取得。商品別注文数の総和は複数商品注文があるため全体注文数に一致しない。
- 同一注文または明細の重複は除外し、不完全な期間として扱う。欠損・不明状態・上限500注文/5000商品明細に達した場合は比較を確定しない。取得期間に商品が存在しないことと、明細自体が未取得であることを分ける。
- 取得成功から36時間を超える、未来時刻、取得失敗では古い参考値と表示し、減少の課題判定を抑制する。Sales APIの売上とOrdersのITEM小計は別定義で、入金/利益ではない。
- 広告・原価・セッション・返品はこの分析に未取得。ROAS・利益・転換率を推測しない。減少は観測差であり、原因を断定しない。
