# SICK STYLE — Canva Free向け引き継ぎ仕様

Canvaデザイン用MCPは未提供のため、Brand Kit・既存デザインの検索やCanvaへの作成・アップロードは未実施。添付SVGはコード作成の検討素材で、Canvaで制作した成果物ではありません。

- ブランド参照: このリポジトリの`public/logo-mark.png`。差し替えず、Canva側に既存素材が見つかれば所有権を確認してそちらを使う。
- 基本色: 既存CSSの背景`#0a0a0b`、面`#141416`、枠`#2c2c31`、文字`#f4f4f5`、補助文字`#9a9aa1`、シルバー`#c7cad0`。正式なBrand Kitを確認した色という意味ではない。
- PC: 1440px、サイドバー248px、本文32px余白。接続状態カードに「認証待ち／同期未検証／接続済み」を文字で表示する。色だけで区別しない。
- iPhone相当: 390px、余白14〜16px、1列、操作対象44px以上。取得元・最終成功・最終試行・失敗を同じカード内で読める順に配置。
- KPI: 未取得は「未取得」、実測0のみ「0」。SalesとOrdersの時刻・期間は別。古い数値に新しい取得日時を付けない。
- 操作: 認可は本人の公式画面へ移動。同期と接続解除を区別する。投稿・DM・広告・価格変更の操作を追加しない。
- 素材: `canva-handoff.svg`は基本図形と文字だけで構成。プレミアム素材・生成AI・外部フォント・外部画像は使用しない。Canva Freeで手動取り込み可能かは本人が確認する。
- 出力前: 既存デザインへ上書きしない。新規下書きで人間レビューし、有料素材やAIクレジットの要求が出れば停止する。
