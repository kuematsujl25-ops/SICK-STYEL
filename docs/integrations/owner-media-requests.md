# 本人専用の素材・Dotへの依頼
「Instagram」タブの上部。既存管理者のセッションを使う。スタッフアカウント追加・アクセス共有は行わない。

- 画像（JPG、PNG、WebP）とMP4の登録・閲覧に対応。1ファイル25 MB。素材は同一Originの認証付きURLから配信し、公開バケットや公開配信用URLは使わない。動画のRangeに対応。
- 制作・修正・投稿予約の依頼をD1に保存する。投稿予約依頼には対象素材と未来の日本時間が必要。依頼の送信・予約・公開を自動実行しない。
- 個人用Dotの既存チャットへ直接投稿するAPIは使わない。専用接続の設定前は **依頼を保存 → 指示をコピー → 既存のDotチャットへ本人が送る**。状態ラベルは未送信で、手動の貼り付け送信は追跡しない。ファイルが必要な指示は別途添付する。
- ChatGPT Libraryや既存のMacフォルダの自動走査は行わない。本人が選んだ素材かDotが納品した指定ファイルだけを登録。
- 素材保管は上限管理・データ保護方針を確認してから、作成した非公開R2バケットをCloudflare Workersの **OWNER_MEDIA** バインディングにする。r2.devや公開ドメインを有効にしない。本番管理手順に沿って設定をバージョン管理し、レビュー・デプロイ前確認を行う。R2未設定時は依頼保存のみ利用でき、素材の登録UIは無効。無料利用枠を前提にバケットを自動作成しない。
- 本番の投稿・予約時に素材を一般公開する手順は追加していない。

## Dotへの受け渡し接続（未有効化）
専用のランダムな32バイトのキーをWorker Secret（16進表記の `OWNER_DOT_BRIDGE_TOKEN`）と正規のDot側実行環境に登録した場合に限り「Dotに送る」ボタンが表示される。設定は受信側を検証してから行う。認証情報はチャットやGitに貼らない。これは個人DotのChatGPT会話APIではない。

- `GET /api/owner-media/dot/queue` は本人が送った処理中の依頼だけを返す。下書き・個人チャット・他の業務情報は返さない。
- `POST …/receive`（`{id}`）、`POST …/complete`（`{id,result}`）で、実際の受取・処理後にアプリへ反映。再試行は同じIDで行い、結果の上書きは拒否。受信側はIDで重複作業を防止し、予約依頼を承認済みの投稿とみなさない。
- `GET …/files/{id}` で処理中の依頼に指定された素材のみ取得可。 `POST …/files` はDotのSICK STYLE向け成果物専用。Content-TypeとURIエンコードした `X-Sickstyle-Media-Name`、本文はバイナリ。素材一覧・他データにアクセスする権限は付与しない。
- すべてAuthorization: Bearerの専用認証。ブラウザCookieとCORSでの実行を許さない。接続解除時は、Worker Secretと受信側のキーを削除する。
- 受信先の常時稼働・過去成果物の一括取込はこの接続には含まない。接続未設定時に送信・予約完了とは表示しない。

## 本人端末での初回接続
1. 既存の非公開R2をバインドした版を通常のレビュー・本番反映手順で反映する。
2. 本人がMacのターミナルで `node scripts/set-secrets.js owner-dot-bridge --apply` を実行し、対象Workerと権限範囲を確認する。キーの手入力やチャットへの貼り付けは不要。既存キーがあれば上書きしない。同じMacへの保存と受信口の読み取り確認だけで、他サービスやInstagramの認可は変更しない。
3. Dot側で `node scripts/owner-dot-bridge.js queue` が成功することを確認する。Macがオフラインまたはアクセスできない場合は受信できず、アプリ上では受取待ちになる。Instagram連携の読み取り状態は変えない。

### 受け渡し
- Dotがこの事業用に制作した、本人に納品済みの具体的なファイルだけを指定し、`node scripts/owner-dot-bridge.js upload /絶対パス` で非公開ギャラリーへ登録する。一括取込や公開リンク化は行わない。失敗で登録結果が不明な場合はギャラリーを確認してから再試行する。
- アプリから「修正を依頼」または「投稿予約を依頼」→依頼保存→「Dotに送る」。アプリのキューで実際の受取を確認してから `receive ID`、その依頼に付いた素材だけ `download 素材ID /未作成の保存先`、結果の登録は `complete ID` に結果テキストを標準入力する。依頼を保存しただけでは送信・予約されない。
- 投稿依頼は非公開の素材・文面・希望日時・公開判断の準備に限る。投稿依頼で「Instagram内で追加（曲名・アーティスト）」「動画に入っている音を使用」「BGMを追加しない」を任意指定できる。実予約・投稿は対象アカウント、素材、文面、日時、音楽を本人が別途承認してから。指定した音源が使えない場合、無断で別の曲を設定しない。Dot連携にはMetaの投稿、広告、DM権限は不要。依頼内容を理由にローカルファイル全体や別サービスへアクセスしない。
